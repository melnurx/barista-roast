# Deployment

The production build is a Cloudflare Worker plus static browser assets, generated by the OpenAI Sites/Vinext starter. `npm run build` produces `dist/server/wrangler.json`; `npm start` serves that production build locally. It was verified to return HTTP 200.

The local demo needs no runtime secrets or database. Optional live AI uses server-only `OPENAI_API_KEY`, `OPENAI_MODEL`, and `OPENAI_TRANSCRIBE_MODEL` environment values.

## Hosted publication status

Sites created the project recorded in `.openai/hosting.json`, but later both its credential-refresh and project-read endpoints returned **404: Sites project not found**. Publication did not complete. No hosted URL is being claimed as live.

The project identity is retained for recovery; do not create a duplicate project or replace that identifier to work around an access error. Reconnect/select the account that owns the existing Site, retrieve it using the recorded project ID, then use the Sites source workflow to push/package and publish the verified source.
